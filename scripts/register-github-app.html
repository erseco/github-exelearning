Register the eXeLearning GitHub App

Open this file in your browser while signed in to GitHub. GitHub shows the app (name, permissions) before creating it; you can rename it there if the name is taken.

Afterwards GitHub sends you to https://github.exelearning.dev/setup.html, which shows a one-time code (valid for 1 hour) to finish the setup:

gh api -X POST /app-manifests/CODE/conversions
